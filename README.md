# Elan Pattern Studio — GitHub Pages upload

1. Create a NEW repository on GitHub, for example elan-pattern-studio. Do not use the FortInsight repository.
2. Upload index.html, manifest.webmanifest and the icons folder from this folder to the repository root (Add file > Upload files), then commit them to main. Upload .nojekyll too if visible; the single HTML works without it.
3. Open repository Settings > Pages.
4. Under Build and deployment choose Deploy from a branch, main, /(root), then Save.
5. Wait for the published link shown in Pages, then open it on your phone. It normally looks like https://YOUR-USERNAME.github.io/elan-pattern-studio/.
6. Bookmark the link or use your phone browser's Add to Home Screen option if available.

The site has NOT been uploaded or published for you. A public repository and public Pages site expose the app source and let other people use the app. Do not choose that approach if you want this app kept private.

Use index.html, not the work folder or your entire Codex folder. The editor is embedded in index.html. Home-screen and browser icons also need manifest.webmanifest and the icons folder. Upload these together when updating the app.

Saved patterns and measurements are browser-local: your laptop's saved work will not automatically appear on your phone. Local-server AI photo analysis is not hosted by this static Pages upload.

Projector: a pattern opens immediately and the cutting mat is on by default. There is no calibration square. Expand Calibrate using mat rulers; use Calibrated cutting view at 100% scale, and measure 0–4 inches horizontally and vertically on the physical fabric (or 0–100 mm). Enter those measured spans and apply. Recheck the physical ruler spans. A fitted preview is not a cutting scale.

Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
